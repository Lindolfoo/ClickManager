Política de Privacidade

Última atualização: 9 de julho de 2026

Esta política explica quais dados o Click Manager coleta, para que usa e quais direitos você tem sobre eles, em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 — LGPD).

1. Quem somos

O Click Manager é uma plataforma de gestão para fotógrafos autônomos, desenvolvida como projeto acadêmico (PIM III — UNIP, curso de Análise e Desenvolvimento de Sistemas). Para qualquer dúvida sobre esta política ou sobre seus dados, entre em contato pelo e-mail contato@clickmanager.com.br.

2. Quais dados coletamos

  • Dados de cadastro do fotógrafo: nome, e-mail, telefone, senha (armazenada com hash, nunca em texto puro), Instagram e biografia opcionais.
  • Dados inseridos pelo fotógrafo sobre terceiros: nome, e-mail e telefone dos clientes/contratantes que ele cadastra na plataforma, além de dados dos ensaios, contratos e pagamentos.
  • Imagens: fotos enviadas para portfólio público ou para a galeria de entrega de um ensaio.
  • Dados técnicos: registros de autenticação (token JWT) e, quando aplicável, logs de acesso para fins de segurança.

O fotógrafo é responsável por obter o consentimento adequado dos seus próprios clientes antes de cadastrar os dados deles na plataforma.

3. Para que usamos os dados

  • Criar e autenticar sua conta;
  • Disponibilizar as funcionalidades do sistema (clientes, ensaios, contratos, pagamentos e galeria);
  • Enviar e-mails transacionais (redefinição de senha, contato);
  • Gerar o link público de entrega de galeria, quando você optar por criá-lo;
  • Cumprir obrigações legais e resolver disputas.

Não vendemos nem compartilhamos seus dados com terceiros para fins de publicidade.

4. Com quem compartilhamos

Seus dados ficam hospedados em provedores de infraestrutura contratados para operar o serviço (banco de dados e servidor de aplicação). O envio de e-mails transacionais é feito através de um provedor de SMTP. Esses provedores têm acesso aos dados apenas na medida necessária para prestar o serviço contratado.

5. Galeria e portfólio públicos

Imagens de portfólio e os links públicos de galeria de entrega são, por natureza, acessíveis a quem tiver o link — não exigem login. Não inclua nessas imagens informações sensíveis que não devam ser vistas por terceiros. Você pode revogar um link de galeria a qualquer momento na tela "Galeria do Ensaio".

6. Seus direitos (art. 18 da LGPD)

Você pode, a qualquer momento:

  • Acessar e corrigir seus dados de cadastro em "Configurações";
  • Excluir sua conta e todos os dados associados — clientes, ensaios, contratos, pagamentos, imagens e link de recuperação de senha — de forma definitiva e imediata, em "Configurações → Excluir conta";
  • Solicitar uma cópia dos seus dados ou esclarecer qualquer dúvida escrevendo para contato@clickmanager.com.br.

A exclusão de conta é irreversível: uma vez confirmada, os dados não podem ser recuperados.

7. Retenção de dados

Mantemos seus dados enquanto sua conta estiver ativa. Ao excluir a conta, os registros são apagados imediatamente do banco de dados de produção.

8. Segurança

Senhas são armazenadas com hash (BCrypt), nunca em texto puro. O acesso à API é protegido por autenticação JWT, e cada fotógrafo só enxerga os próprios dados — nunca os de outro fotógrafo cadastrado na plataforma.

9. Cookies e armazenamento local

O Click Manager não usa cookies de rastreamento ou publicidade. O token de sessão (JWT) é guardado no localStorage do seu navegador, apenas para manter você conectado.

10. Alterações nesta política

Podemos atualizar esta política eventualmente. A data no topo desta página indica a versão mais recente.
